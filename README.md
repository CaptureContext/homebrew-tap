# capturecontext tap

Homebrew tap for CaptureContext tools

## [skillrack](https://github.com/capturecontext/skillrack)

A managed registry for agent skills shared across coding tools.

### Requirements

- macOS 15 or later

### ⌘ Install

```bash
brew install capturecontext/tap/skillrack
```

### ⌘ Update

```bash
brew upgrade skillrack
```

## [fxcodex](https://github.com/capturecontext/fxcodex)

A macOS CLI for managing isolated Codex workspaces.

### Requirements

- macOS 14 or later

### ⌘ Install

```bash
brew install capturecontext/tap/fxcodex
```

### ⌘ Update

```bash
brew upgrade fxcodex
```
